Desktop-приложение (WinForms, .NET) для внутреннего документооборота и отчётности условного газотранспортного предприятия: ролевой доступ, сменные/квартальные/годовые отчёты, прогнозирование объёмов, генерация документов в Word и уведомления в Telegram.

Проект выполнен в фирменном стиле компании (GazpromStyle) как учебный курсовой проект, имитирующий реальный корпоративный процесс отчётности.

Возможности
Аутентификация и роли. Вход по логину/паролю, заявки на регистрацию новых пользователей, разграничение видимости разделов меню по статусу пользователя (сотрудник филиала, менеджер, HR, бригада посменно, администратор).
Управление филиалами. Список филиалов с адресом, контактами и привязкой ответственного менеджера.
Отчётность в три уровня:
Сменные отчёты — фиксация показателей по сменам с привязкой к бригаде и филиалу.
Квартальные отчёты — создание, просмотр и сортировка по столбцам таблицы (клик по заголовку).
Годовые отчёты — агрегированные данные за год.
Прогнозирование объёмов. Сервис YearlyForecastService считает динамику по последним 3 годам и строит прогноз объёма газа на следующий год (с процентом роста/падения и текстовым выводом тренда).
План поставки / план работ. Учёт рабочего графика и плана поставки по филиалам.
Генерация документов. Формирование отчётов в формате Word через DocumentFormat.OpenXml (без Microsoft Office на машине).
Уведомления в Telegram. Мост TelegramBridge пишет события (новая заявка, новый отчёт, действия с пользователями) в отдельную таблицу БД, которую читает Telegram-бот и рассылает уведомления ответственным.
Резервное копирование БД — пункт меню для администратора.


Проект не подключается к внешней/существующей БД предприятия — вся схема (филиалы, пользователи, отчёты, уведомления) создаётся и заполняется тестовыми данными самим приложением при старте при отсутствии бд или использует данные если оно существует.
Это осознанное решение для автономного демо/учебного проекта.
