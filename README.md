Desktop-приложение (WinForms, .NET) для внутреннего документооборота и отчётности условного газотранспортного предприятия: ролевой доступ, сменные/квартальные/годовые отчёты, прогнозирование объёмов, генерация документов в Word. База данных — PostgreSQL.

Проект выполнен в фирменном стиле компании (GazpromStyle) как учебный курсовой проект, имитирующий реальный корпоративный процесс отчётности.

Возможности
Аутентификация и роли. Вход по логину/паролю, заявки на регистрацию новых пользователей, разграничение видимости разделов меню по статусу пользователя (сотрудник филиала, менеджер, HR, бригада посменно, администратор).
Управление филиалами. Список филиалов с адресом, контактами и привязкой ответственного менеджера.
Отчётность в три уровня:
Сменные отчёты — фиксация показателей по сменам с привязкой к бригаде и филиалу.
Квартальные отчёты — создание, просмотр и сортировка по столбцам таблицы (клик по заголовку).
Годовые отчёты — агрегированные данные за год.
Прогнозирование объёмов. Сервис QuarterlyForecastService считает динамику по последним 3 кварталам и строит прогноз объёма газа на следующий квартал (с процентом роста/падения и текстовым выводом тренда).
План поставки / план работ. Учёт рабочего графика и плана поставки по филиалам.
Генерация документов. Формирование отчётов в формате Word через DocumentFormat.OpenXml (без Microsoft Office на машине).


База данных — PostgreSQL. При первом запуске программа спрашивает параметры подключения (сервер, порт, база, пользователь, пароль) и сохраняет их в config.json рядом с exe. Если базы ещё нет, программа сама создаёт её, все таблицы и заполняет их тестовыми данными; если база уже есть — использует существующие данные.

Работа с БД (папка SQL):
DB_Create — создание базы и таблиц; DB_Fill — заполнение начальными данными;
DB_Users — пользователи; DB_Requests — заявки на регистрацию; DB_Filials — филиалы; DB_WorkSchedule — график работы;
DB_ShiftReport — сменные отчёты; DB_QuarterlyReport — квартальные; DB_YearlyReport — годовые; DB_WorkPlan — план поставки.
